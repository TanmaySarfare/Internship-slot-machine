# The Internship Slot Machine

> I used to gamble. Now I apply to internships. Same dopamine. Worse odds.

A casino-themed parody game: every pull of the lever is one internship application.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```
